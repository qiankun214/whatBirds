        WhatBird 通过火山方舟（Ark）调用 Doubao-Seed-2.1 识别鸟类，所以需要先准备一个方舟 API Key。

        1. 打开火山方舟控制台： console.volcengine.com/ark
        2. 在「API Key 管理」中创建一个 Key，并复制下来（只显示一次）。
        3. 确认已开通 Doubao-Seed-2.1 系列模型。模型详情见 doubao-seed-2-1-lite。
        4. （可选）在「在线推理」创建一个推理接入点，稍后把接入点 ID（ep-xxxxxxxx）填到模型一栏。

        Key 只会保存到本机用户目录，仅用于调用火山方舟；不会写入项目、也不会进 git。

        不确定就保持默认：图片会按最长边等比缩小以节省 token，识别任务建议 temperature 保持较低。

        「测试连接」用当前填写的内容试调一次方舟，不会写盘；「保存配置」会写入 —，一次配置长期有效。
