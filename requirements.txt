# Runtime dependencies. Install with the Tsinghua mirror (mainland China):
#   python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt
#
# Versions are pinned to the exact set this project was developed and tested with.
# Pinning also matters for speed: with open ranges pip 23 has to fetch metadata for
# every candidate version of every package, which on the Tsinghua mirror can stall
# for a very long time.
#
# Keep this file ASCII-only: pip reads it with the system locale encoding (GBK on
# Chinese Windows), so non-ASCII comments can raise UnicodeDecodeError.
#
# Notes:
# - openai 1.x : Ark's official docs and examples use the 1.x chat.completions API
# - pydantic 2 : the core/web layers use pydantic v2 model_dump()
# - opencv-python-headless : traditional-CV focus analysis. Headless (not the GUI
#   build) because we only need cv2's image ops, and it has no GUI dependency so it
#   also installs on a server without a desktop.
# - numpy is pinned explicitly because whatbird/core/focus/content.py imports it
#   directly; it must not float with whatever opencv happens to pull in.
# - exifread : pure-Python EXIF/MakerNote reader for the camera's focus point.
#   BSD-3-Clause. (python-exiv2/libexiv2 is more complete but is GPL-3.0 and ships
#   a 9 MB binary wheel, which would change this project's licensing.)
# - numpy 1.26.x is the line this was developed against; re-run the focus tests
#   before bumping it to 2.x.
